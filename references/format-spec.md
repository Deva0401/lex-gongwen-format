# 公文排版视觉格式规范

本规范源自《议案模板（股权投资）》，适用于国企/体制内议案、请示、报告等公文的排版。

## 1. 页面与正文全局

| 项目 | 规范 |
|---|---|
| 页边距 | 上 2.54 cm、下 2.54 cm、左 3.18 cm、右 3.18 cm |
| 中文字体 | 仿宋_GB2312（非 Windows 平台见 [font-mapping.md](font-mapping.md) 映射） |
| 中文字号 | 三号 |
| 数字/英文字体 | Times New Roman（Linux 可用 Liberation Serif 替代） |
| 数字/英文字号 | 与中文同层级对应 |
| 行距 | 固定值 30 磅 |
| 段前间距 | 0 行 |
| 段后间距 | 0 行 |
| 首行缩进 | 2 字符 |
| 对齐方式 | 两端对齐 |
| 抬头 | 不缩进（如"公司总经理办公会："顶格） |
| 金额单位 | 全文统一为"万元/亿元"，不得混用 |

> 页边距为模板固定要求（上 2.54cm / 下 2.54cm / 左 3.18cm / 右 3.18cm）。排版脚本 `scripts/docx_format.py` 会自动应用；人工排版时在 Word「布局 → 页边距 → 自定义页边距」中按上述数值设置。

> 字体跨平台映射见 [font-mapping.md](font-mapping.md)：Windows 使用中易字库（仿宋_GB2312/华文中宋/楷体_GB2312），macOS/Linux 使用开源 OFL 字体（朱雀仿宋/思源宋体/霞鹜文楷等），避免缺字导致版式错乱。

## 2. 标题层级

公文标题分四级，**不得跳级**。

### 一级标题

- 示例："一、项目基本情况""二、投资的必要性及可行性"
- 字体：华文中宋
- 字号：二号
- 字形：加粗
- 对齐：居中

### 二级标题

- 示例："（一）XX基金介绍""（二）项目简介"
- 字体：黑体
- 字号：三号
- 字形：常规（不加粗）

### 三级标题

- 示例："1.投资标的——XX公司""2.项目公司——XX公司"
- 字体：楷体_GB2312
- 字号：三号
- 字形：加粗

### 四级标题

- 示例："（1）公司简介""（2）股权结构及实际控制人"
- 编号格式：统一使用"1.，2.，……"样式的阿拉伯数字点号编号体系（三级用"1."，四级用"（1）"）
- 字体：仿宋_GB2312
- 字号：三号

## 3. 表格

### 表题

- 位置：表格上方
- 格式："表X  XXX表"（X 为表格序号）
- 字体：仿宋_GB2312
- 字号：小四
- 字形：加粗

### 表格正文

- 字体：仿宋_GB2312
- 字号：小四
- 行距：固定值 20 磅（注意：区别于正文的 30 磅）

### 数值格式

- 千位分隔符：使用
- 小数位数：保留 2 位

### 单位标注

- 表题下方注明单位，如"单位：万元/亿元"或"单位：万元/亿元，%"

## 4. 图片与架构图

### 图题

- 位置：图片下方
- 格式："图X  XXX图"
- 字体：仿宋_GB2312
- 字号：小四
- 字形：加粗

### 交易架构图/结构图

- 边框颜色：黑色
- 文字颜色：黑色
- 图内字体：微软雅黑
- 制作方式：必须使用 Word/PPT 等可编辑方式绘制，**不得使用截图**
- 图中要素：
  - 出资主体名称须使用规范简称
  - 须列明本次投资方案的出资主体、投资金额、担保方等重点要素

## 5. 正文内强调

- "**一是**""**二是**""**三是**"等序号词需**加粗**，后续正文不加粗。

## 6. 落款

- 单位名称
- 日期：20XX年XX月XX日
- 联系人信息：（联系人：XXX，联系电话：XXX XXX XXX）

## 7. 易遗漏点检查清单

排版完成后逐项核查：

- [ ] 页边距是否为上 2.54cm、下 2.54cm、左 3.18cm、右 3.18cm
- [ ] 正文中文字体是否为仿宋_GB2312三号
- [ ] 数字和英文是否为 Times New Roman
- [ ] 正文行距是否为固定值30磅（不是多倍行距）
- [ ] 段前段后是否均为0行
- [ ] 首行缩进是否为2字符
- [ ] 抬头是否顶格不缩进
- [ ] 一级标题是否华文中宋二号加粗居中
- [ ] 二级标题是否黑体三号
- [ ] 三级标题是否楷体_GB2312三号加粗
- [ ] 四级标题是否仿宋_GB2312三号
- [ ] 标题是否跳级
- [ ] 表题是否在表上方、仿宋_GB2312小四加粗
- [ ] 表格正文行距是否为20磅（非30磅）
- [ ] 图题是否在图下方、仿宋_GB2312小四加粗
- [ ] 架构图边框/文字是否为黑色、字体是否微软雅黑
- [ ] 架构图是否为可编辑对象（非截图）
- [ ] "一是""二是"是否加粗
- [ ] 数值是否使用千位分隔符并保留2位小数
- [ ] 全文金额单位是否统一
